# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2025-04-10

### Added

- Add HDPI support for screen resolution bigger than `600x600`.
- Add dynamic gauge color update depending on the power value.

### Fixed

 - Fix gauge flickering issue.
 - Fix circle arcs rendering issue.

### Changed

 - Migrate project to SDK6.
 - Optimize UI performances with drawings caching.
 - Remove deprecated observer class usage.

## [1.0.0] - 2024-05-30

### Added

 - Initial release of UI example project.
